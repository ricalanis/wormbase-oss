# Case studies

Characterizations of adjacent systems and the patterns WormBase
borrows, generalizes, or deliberately does not import. Each case study
distills a load-bearing primitive and traces it to where WormBase
expresses it (or where the institutional analog requires a net-new
shape).

## Index

- [openclaw-integration-patterns.md](openclaw-integration-patterns.md)
  — OpenClaw's channel onboarding pattern, the three load-bearing
  primitives (unified verb, status-honest capability badges, probe-as-a-
  verb), and the institutional-onboarding analog `@onboard <object>`
  that extends it across the institutional ontology.
