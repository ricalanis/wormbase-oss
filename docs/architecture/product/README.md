# Product

Cross-subsystem walkthroughs and proposals that describe how WormBase
shows up to its users — installers, domain owners, org members,
external agents — and where the seams between subsystems live.

## Index

- [customer-journey.md](customer-journey.md) — Stage-by-stage
  walkthrough of the customer journey from discovery through day-100
  operating state. Identifies the four big architectural seams
  (conversation-vs-external-lake silo at the MCP surface; onboarding
  tier ↔ semantic-layer journey; worm ↔ agent interaction asymmetry;
  generalized compounding loop).
- [institutional-onboarding-proposal.md](institutional-onboarding-proposal.md)
  — Architectural proposal for translating OpenClaw's onboarding
  pattern into an institutional-scale shape. Five durable properties,
  five tier flow, phased delivery, open decisions.
