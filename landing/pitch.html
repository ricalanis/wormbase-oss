04 · what it is

An agent that tends a lake of your org's knowledge.

It installs in two places: your chat platform (Slack / Discord / Teams) and your data lake (or it builds one).

From the moment of install, the lake exists because the agent is tending it. There is no pre-existing lake the agent shows up to operate. Agent and lake co-emerge.

Eight named loops run continuously from t=0. Every action is hash-chained to a Postgres ledger. Every answer comes with a receipt.

conversation
Threads, mentions, decisions

Bronze ingestion from the first wire event — messages, files, reactions.

external
Postgres · Snowflake · Stripe · MCP

Connect what you have. The agent catalogs, classifies, watches.

filedrop + evidence
CSVs, PDFs, notebooks

Drop a file in Slack — it lands in the lake, profiled and provenanced.

10 · what's different

Three properties no vendor has all three of.

  • Deterministic + auditable. Every write is hash-chained. Every answer is replayable from the ledger. No black-box LLM in the write path.
  • Compounding wiki of org truth. Karpathy LLM-Wiki, but built from your actual work — not bootstrapped from corpora.
  • Metric-governed self-improvement. Per-user autoresearch loop. Each role (CFO, COO, eng) gets their own analyst seat that gets sharper.

moat  The longer you run, the more the ledger remembers. Switching cost is the work you've already done.
