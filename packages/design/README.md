# @wormbase/design

TypeScript design tokens + primitive components implementing the Field Notebook direction (PRD §4.4): warm off-white paper, aged-ink charcoal, botanical green, sepia warnings, serif narrative, monospace for ledger content, breathing-gauge motion. Consumed exclusively by `apps/dashboard`; primitives include `Button`, `Input`, `Select`, `Card`, `Receipt`, `Gauge`, `LedgerEntry`, and `Page`. Browse the visual review with `pnpm --filter @wormbase/design story` once Phase 1A lands the system.
